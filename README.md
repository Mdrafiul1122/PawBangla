# Project 3: Pet Adoption Portal

## Project Overview
A website where people can find and adopt pets from animal shelters.

## User Roles
- Admin – manages pets and adoption requests
- User – searches pets and applies for adoption

## Main Features
1. Pet List – shows available pets
2. Search – helps users find pets
3. Apply – users can apply to adopt a pet
4. Approve Adoption – admin can approve or reject requests
5. Success Stories – shows successful adoptions
6. Responsive Design – works on mobile and PC
7. Filter – filters pets by type, age, etc.
8. Profile – users can manage their profile
9. Dashboard – shows important information

## Database Tables
- users – user information
- admin – admin information
- pets – pet information
- adoption_requests – adoption applications
- notifications – user notifications

## Unique Feature
### Pet Compatibility Score
The system gives a score to show how suitable a pet is for a user based on their preferences.

Example:
User likes: Dog + Small + Friendly
Pet: Dog + Small + Friendly
Compatibility: 95%

## Optional Features
- Notifications – shows messages inside the website
- Dark Mode – allows light/dark mode
- PDF Report – allows reports to be downloaded as PDF
